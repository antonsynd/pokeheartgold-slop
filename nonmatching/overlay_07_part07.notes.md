# overlay_07 part 07

All 30 functions (ov07_0221FA38 to ov07_0221FF74) pass check.py (2000 trials each).

- The twin tool's matches are by name order only ("found by order 0.50") for about half of this part and several are the wrong Platinum function (ov07_0221FA78 is a palette getter, ov07_0221FAE8 returns 1, ov07_0221FAEC and ov07_0221FAF8 are lookups into small `{1, 2, 3}` tables, ov07_0221FB78 returns 0). Those were written from the asm. The real twins are ov07_0221FA38, FA80, FA90, FAA0, FAB0, FAC8, FB30, FB58, FB7C, FB90 to FE70 (battle_anim_system.c) and FE88 to FF34 (battle_particle_util.c, emitter_callbacks.c).
- ov07_0221FB04 returns the `switch` result for backgrounds 0 to 3 (0, 1, 3 and the result of ov07_0221FAE8) and leaves r0 untouched for anything else, i.e. it returns its own first argument. The C returns `(int)a0` after the switch to say so; the game only passes 0 to 3.
- ov07_0221FAE8 ignores its argument and returns TRUE (Platinum's contest test is gone in HeartGold).
- ov07_0221FB90 builds a 0x58 byte record: heap id at 0x0, the battler filter at 0x4 (0xFF means all four), sprite system / manager / palette data at 0x8, 0xC, 0x10, four resource ids at 0x14, four ManagedSprite pointers at 0x24, four pokemon sprite data pointers at 0x34 (UnkBattleSystemSub1D0: tiles, narc id, palette, y offset), four battler type bytes at 0x44 and four Pokepic pointers at 0x48. Resource ids are 55555 + battler + filter * 5000. The ManagedSpriteTemplate is the fork's (0x34 bytes). The `{0, 0, 20, 10, 10, 20}` priority table is a local array here as in Platinum (ROM copy ov07_02234BD8). The sprite palette buffer is PLTTBUF_MAIN_OBJ, and the palette destination is `(u16)(offset << 4)`.
- The battle animation system object read here has its context pointer at 0xC0, the BgConfig at 0xC4 and the PaletteData at 0xC8. Context fields used: 0xB0 sprite data pointers[4], 0xC4 Pokepic pointers[4], 0xD4 battle type flags (bit 1 is double battle), 0xEC personalities[4], 0xFC move effect flags[4], 0x110 BG tile data, 0x114 BG palette buffer.
- `_02234B80` (`{1, 2, 3}`), `ov07_02234B8C` (`{1, 2, 3}`), `ov07_02234F48` (rows of five ints) and `ov07_022353E4` (emitter callbacks) are only declared; their contents are the ROM's.
- sub_02015494 is declared locally as returning the emitter (the fork's header says `void`, but ov07_0221FF18 returns its result). The fork's `overlay_06.h` and `unk_02014DA0.h` are not included for that reason.
