# overlay_01_021F1348 part 1

- Tail calls: FieldEffectManager_InitAnimManagerList, FieldEffectManager_Render, ov01_021F1448, ov01_021F1490, ov01_021F149C and ov01_021F14A8 end in `ldr r3, =callee; bx r3`. check.py reports FAIL "only one side returned": the lifted original jumps out of its unit and never reaches the return address, while the compiled C makes a normal call and returns. The C in each case is the call the asm makes with the arguments it sets up (`NARC_Delete(manager->narc)`, `NARC_GetMemberSize(manager->narc, memberId)`, `NARC_ReadWholeMember(manager->narc, memberId, dest)`, `Heap_Free(ptr)`, `ov01_021F1610(manager)`, and for InitAnimManagerList the store of the count at +0x8 followed by `ov01_021F15EC(manager)`). This is the gate's tail-call limit, not a behavioural difference. A `musttail` form was not used because it only yields a vacuous result (both sides unfinished).
- ov01_021F1430: the logic is `memset(ov01_021F141C(manager, size, atEnd), fill, size)`. check.py reports a memory difference near the end of the memset range (address 0xffe4 with a destination of 0). The sandbox clamps memset to 0x10000 bytes, and its write log holds at most 65536 distinct byte addresses; the -O0 frame of the C writes 28 bytes before the memset (push, four argument spills, one local) where the original writes 16 (`push {r4, r5, r6, lr}`), so the last bytes of the clamped memset are logged on one side and dropped on the other. Any trial with a size of 0x10000 or more shows it, and the size is a random 32-bit value.
- `include/overlay_01_021F1348.h` is not included. It declares `FieldEffectManager` as `u8 unk0[0x24]`, `ov01_021F1450` as taking a `FieldSystem *` (the asm passes the manager: it calls `ov01_021F1588(manager, id)` on the same register) and `ov01_021F146C` as returning `FieldSystem *` (it returns the `FieldEffectManager *` at FieldSystem+0x44). Any definition here would conflict with those prototypes, so the file defines `UnkStruct_Ov01_021F1348` (the manager: heap id at 0x00, renderer count at 0x04, anim manager count at 0x08, field system at 0x10, renderer array at 0x14, NARC at 0x18, anim manager at 0x1C, an unknown pointer at 0x20) and a renderer slot of 8 bytes (id, data; id 0x17 marks a free slot).
- ov01_021F1468 takes the FieldSystem and returns its task manager (+0x10); the header agrees. A local view of FieldSystem with `taskman` at 0x10 and `fieldEffectManager` at 0x44 is used because `field_system.h` pulls in the header above.
- The NARC opened by ov01_021F147C is `NARC_a_1_0_3` (0x67). `ov01_02208C5C` (defined in src/overlay_01_data_02208BFC.c) is a table of 12-byte entries (id, constructor, destructor) ended by id 0x17.
