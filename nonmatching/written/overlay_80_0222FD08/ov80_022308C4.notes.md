usedSpecies/usedItems are u16[8] arrays at entry_sp-0x24 / entry_sp-0x34 in the original (push {r4-r7, lr} then
locals), and Party_GetCount can return values that index far outside them (the check feeds random counts, and the
stores then land at the same absolute addresses in both versions). The C reproduces those addresses with
__builtin_frame_address(0) + 8 (= entry sp with the compiler's frame pointer) and keeps its own locals below them
via the unused framePadding array. This is compiler-layout dependent but deterministic for the check's flags.
