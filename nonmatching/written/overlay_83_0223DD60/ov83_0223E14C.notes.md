# ov83_0223E14C: PASS

Battle Castle self-app main flow, a 23-state switch on `app->subState` (+0x08); anything above 0x16 returns 0.
Written from the asm, not from the Platinum twin (HeartGold's version uses TouchscreenListMenu / YesNoPrompt and a
6-per-page item grid in states 9/10/11, and has no UpdateSelectedMon input path). `bl _0223EE86` in the asm is a far
branch to the common `return 0` epilogue. Menu results are compared as unsigned (-2 is cancel, -1 nothing chosen, -3
a grid "blocked" result), so the switches use u32 cases. The tables ov83_02247F4C (12-byte rows, rank in word 0),
ov83_02247D18, ov83_02247D48 and ov83_02247D4E are the ROM's and are indexed unchecked (menuPos, rank), exactly as
the asm does. FrontierSave_GetStat's result in state 2 / entry 4 is discarded, as in the asm. The state struct is a
local layout with only the offsets the asm touches (checked with static asserts).
