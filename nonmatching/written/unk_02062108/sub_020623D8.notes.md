# sub_020623D8: PASS

The C copies nothing to a local table: for idx 0..3 it returns the ROM table entry at 0x020FDA28, and GF_AssertFail is
called for idx >= 4 (signed), as in the asm. The original indexes its stack copy of the table without a lower bound or
an upper bound after the assert, so for idx outside 0..3 it reads `entry_sp - 0x18 + 4*idx`. That is reproduced:
idx 4 = the caller's r4 (pushed by the prologue; read from r4 as the first statement), idx 5 = the entry lr
(`__builtin_return_address(0)`), idx >= 6 and idx < 0 = memory relative to the entry stack pointer
(`__builtin_frame_address(0) + 8` under the check's clang -O0 Thumb build). The C is kept free of extra locals so its
frame (push {r7, lr}; sub sp, #16) stays within 0x18 bytes of the entry sp and does not overwrite the words that
negative indices read. Exact for in-range inputs; the out-of-range reads are the stack-relative reproduction.
