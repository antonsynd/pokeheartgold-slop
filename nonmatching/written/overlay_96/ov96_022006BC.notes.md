# ov96_022006BC

Rewritten from the asm (the Ghidra draft was dropped). A state machine on `data->unk164` (0..3) with a 2-entry
index at `unk168`: it raises the Y of the object pair `unk150[idx]` / `unk150[idx + 2]` by 0x20000 per call
through ov96_021EB594 / ov96_021EB588, clamps at 0x1d8000 (state 0), 0x288000 (state 2) or 0x230000 (state 3),
and advances. State 1 calls ov96_02200454 and steps the `u16 unk160[idx]` counter (0 -> 2, else -1). State 3
ends with `ov96_02200BD8(data, (u8)((param1 + 2) % 3))`, resets the state and returns TRUE. `(idx + 1) % 2` is
signed, as in the asm. The earlier mismatch (ov96_02200BD8 argument) was the draft taking the wrong register.
