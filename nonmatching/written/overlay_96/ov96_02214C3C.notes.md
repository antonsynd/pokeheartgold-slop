The fifth argument (entry sp + 0) is copied to a local at entry. The original writes it back (param + 0x4c) before the
last call on one branch; the C does the same through the entry stack pointer, read with an inline `mov sp` at entry.
That offset is 88 for this compile (16 bytes of pushes plus a 72-byte frame), so it must be re-measured if the body changes.
