# ov96_021FF764: PASS

Rewritten from the asm (the Ghidra draft had the two out-parameters of ov96_021EB0A4 swapped, which is why the
second ov96_021EAF78 call saw 0 instead of 0x400000). Four 0xd4-byte entries; for each pair (i, j) it gets both
objects' positions, nudges an x by 1024 when one entry is past 0x300000 and the other below 0x100000, tests the
circles' overlap, and on contact resets velocities, sets the flags, writes the contact point to param_3 (once)
and returns 1.

Reads of uninitialised stack the original also makes, kept uninitialised here (the callee fills them in the
game): the y outputs of ov96_021EB0A4 and ov96_021EAF78's radius outputs (stack arguments), and `savedId`
(stack slot +0x20), which the asm only stores when VEC_Mag(velocity) != 0 but reads on every contact. No
index runs outside a table. The 4th register (r3, pushed by the prologue) is never read, so the function takes
three parameters.
