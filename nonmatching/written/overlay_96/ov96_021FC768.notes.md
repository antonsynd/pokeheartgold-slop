# ov96_021FC768: PASS

Ghidra's draft with these fixes (all from the asm):
- `uRam021d1175` is a byte store; callees `ov96_021EB564`, `ov96_021EB588`, `ov96_021EB630` take 2 arguments.
- `_s32_div_f(a, b)` is declared `unsigned long long _s32_div_f(int, int)`: quotient in r0, remainder in r1. The asm
  calls it twice per site with the same operands and uses the first call's remainder and the second call's quotient
  (cases 3, 4, 5); case 4 calls it four times (rem, quo, rem, quo) per loop turn.
- The real signature has one parameter (r0); the draft's param_2..4 were invented, the pushed r3 is read as the
  function's first statement.
- Case 4 indexes the pair table that starts at sp+0x48 with ov96_021E6138()'s unchecked return value. The table is
  {x48, x4c}, then the 24-byte NARC buffer at sp+0x50, then the rest of the frame, then the caller's frame. The C keeps
  those locals in one struct laid out like the asm's stack (`pf`: x44, x48, x4c, buf[24], rest[0x208] up to the entry
  stack pointer; `rest` is left uninitialised like the asm's unused slots, apart from the saved r3..r7/lr words) and
  `PairWord` reads a word at an offset from the asm's sp, going to real memory past the entry stack pointer
  (`__builtin_frame_address(0) + 8` under clang -O0 Thumb). Exact for in-range indexes.
