The sums live in the original's stack frame and are indexed by an unchecked key read from memory, so a wild key
reaches the saved registers and the caller's frame. The C reproduces that: ov96_021E9570 reserves 0x400 bytes of
stack below its saved registers (so its saved r7/lr sit where the original's do) and a helper uses the original's
frame words at addresses derived from the entry stack pointer (frame address + 8). Counts that make the original
run over its own lr give inconclusive trials (about a quarter).
