The original keeps the list nodes (12 bytes each, head first at sp+8) in its own stack frame and links them by
address. Those addresses reach memory when a link is NULL or wild (a tie-insert that does not leave the loop
corrupts the list), so the C stores the original's stack addresses (derived from the entry stack pointer:
frame address + 8) in the links and NODE() maps them onto a local array of 14 nodes. Counts of 14 or more run
the original over its own saved lr (those trials are inconclusive).
