The asm indexes its local damage array with an unchecked byte (the AI move slot), so for slots >= 4 it reads
the original's own saved registers and the caller's stack.  The C reproduces the original's frame so those
reads agree: the array sits 0x28 bytes below the entry stack pointer, the word above it is the caller's r3, and
the damage calculation is split into a helper so the checked function saves only {r7, lr}.
