# ov112_021E9338

The u16[2] out-buffer the asm hands to sub_02032688 is the stack slot that `push {r3, lr}` filled with
the caller's r3. The C reads r3 on entry with inline asm and starts the buffer from it. On hardware
sub_02032688 overwrites both halves, so only a callee that leaves it untouched (as the check's stub
does) sees the difference.
