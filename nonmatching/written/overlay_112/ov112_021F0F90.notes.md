# ov112_021F0F90

The game indexes its 24-entry stack array of {entry, index} pairs with the unchecked u8 count at
work+0x13E, so indices past 23 reach the saved registers (r3..lr) and the caller's frame, and
`pairs[count - 1]` with count 0 reads the zero word at sp+0. The check feeds random counts, so the
behaviour depends on the exact frame layout.

`ov112_021F0F90` is therefore a naked Thumb shim that builds the game's exact frame
(`push {r3-r7, lr}; sub sp, #0xC8`) and calls `ov112_021F0F90_Body(work, sp)`, which is plain C over
that frame. The function's prototype is declared separately so the check sees the `void` return type.
