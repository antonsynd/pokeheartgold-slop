# ov112_021E9A78

When `kind` is outside 0..7 the asm skips every case and stores r4 into
`data[0x1EC48 + ov112_021FEC80[kind]]` without ever setting r4, so the stored byte is the low byte of the
caller's r4. The C reads r4 on entry with inline asm and stores that. For valid `kind` values it is
plain C.
