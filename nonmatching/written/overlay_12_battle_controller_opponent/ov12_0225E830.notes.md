# ov12_0225E830: PASS

The HeartGold counterpart of Platinum's `Task_PlayerShowBagMenu`: a SysTask callback (`task`, `data`) whose state byte at `data+0xe` selects one of 31 states of the player bag menu (palette fade in, create the bag context, wait for the bag, build the party-menu context, item use message and HP bar animation states, then free everything and destroy the task). State above 0x1e returns (the asm's far `bl _0225F376` to the epilogue). Field offsets follow the asm, not the Platinum twin (data+4 bag context, +8 party-menu holder whose +4 is the party-menu context and +0xc a per-battler byte table, +0xd battler, +0xf battle type, +0x10 cursor, +0x11 text printer, +0x12 next state, +0x17 delay, +0x18 party order, +0x30 embargo bytes).

The message/template structs the asm builds in its 0x214-byte stack frame (sp+0x1c, 0x44, 0x68, 0x8c, 0x20, 0x108, 0x160, 0x1b8, 0xb0) are mirrored in a local frame struct with the asm's offsets (`STK(T, off)` is `[sp, #off]`), so the bytes the asm leaves unwritten (state 8 passes the four bytes at sp+0x1c as a by-value struct in r2) are read from the same unwritten stack. No unchecked index goes past a stack table here, so no entry-stack-pointer-relative read was needed.
