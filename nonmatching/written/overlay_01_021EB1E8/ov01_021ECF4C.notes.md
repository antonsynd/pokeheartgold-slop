Recorded. The original copies the two 4-entry tables onto its stack (v5 at entry_sp - 0x28, v6 at entry_sp - 0x38) and
indexes them with counter / 200 without a bounds check (negative counters read far below the frame). The C uses the ROM
tables for 0..3 and otherwise reads the same absolute stack-relative address as the original, using the frame pointer
(entry_sp - 8) to find entry_sp. Indices -1..-4 / small negatives would see the original's other stack locals, which this
C does not model (the game never has a negative counter).
