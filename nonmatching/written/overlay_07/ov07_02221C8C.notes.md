# ov07_02221C8C

The original copies a 15-word table to its stack and returns `table[behaviorValue]` with no bounds check.
The game only passes valid values; for other values the original reads its own frame (the pushed r3-r5) and
then the caller's stack. The C reads the table for valid indices and models those words for the rest, which
is what lets the check pass on random inputs.
