# ov07_02220CAC

Mode 24 copies a 6-entry table to the stack and indexes it with a battler type, unchecked. `FrameRead` models
the words around the original's frame (emitter, data, end and start types, the copied table, zeros, the six
pushed registers, then the caller's stack). The other modes read ROM tables with `start * 0x48 + end * 0xc`
arithmetic, kept as raw address arithmetic so out-of-range types read the same ROM or fill words.
Checked on 200,000 trials.
