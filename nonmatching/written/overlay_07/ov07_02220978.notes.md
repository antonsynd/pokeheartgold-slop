# ov07_02220978

Types 30, 31 and 32 copy a position table to the stack and index it with a battler type returned by
ov07_02231924, unchecked. `FrameRead` models the original's frame (the copied table, zeros, the five pushed
registers, then the caller's stack) so out-of-range types read the same words as the original. Checked on
100,000 trials.
