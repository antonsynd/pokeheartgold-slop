The terminator test in the asm compares a zero-extended byte with 0xFFFFFFFF, so it never stops
(same bug as Platinum's `!= -1` on a u8). Unknown gift types therefore keep reading stack bytes past
the 0x24-byte table (the pushed r4, then the caller's frame) until one matches. The C reproduces those
reads relative to the entry stack pointer. About 60% of random trials run away in both versions
(inconclusive); the rest agree.
