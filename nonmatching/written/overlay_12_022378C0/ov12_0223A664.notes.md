# ov12_0223A664

Passes (1469 trials agree, 531 inconclusive: runaway loops when sub_02037454() returns a huge count).

The game's loops index netIDs[]/versions[] (stack arrays of 4) by an unchecked connected-player count, and the sandbox
supplies counts far above 4. To behave identically for those inputs the C keeps both arrays in `emu[]`, laid out like the
Metrowerks frame (versions[4], netIDs[4], then the pushed r3-r7/lr), and sends indexes beyond the frame to the memory
above it, found from the frame pointer (entry sp = __builtin_frame_address(0) + 8). The swap also reproduces the asm's
exact read/write order, which matters because versions[4..7] alias netIDs[0..3]. For real inputs (count <= 4) this is
just the sort of the Platinum twin.
