# ov15_02200458

The 8-byte `used` table lives at entry_sp - 0x20 in the asm and is indexed by an unchecked byte
(`GF_AssertFail` does not stop the write). The check feeds random bytes, so out-of-range indexes are the common
case. For indexes >= 0x20 (past the entry stack pointer) the C stores to entry_sp - 0x20 + index via
`__builtin_frame_address(0) + 8` (clang -O0 thumb: `push {r7, lr}; add r7, sp, #0`). Indexes 8..0x1f land in the
asm's own frame (ignored by the check) and are skipped in the C so they cannot clobber the C's own frame.
