The asm indexes a 16-byte stack table (counts[j]) with an unchecked, ever-growing j; once j passes 15 it
reads and increments the frame's saved r4-r7/lr and then the caller's stack. The C models those bytes
(saved registers read via the frame record, caller stack at the entry stack pointer = frame address + 8),
which depends on clang's -O0 prologue. Many inconclusive trials are runaway loops.
