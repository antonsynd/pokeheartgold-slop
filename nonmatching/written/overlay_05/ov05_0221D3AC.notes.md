The real parameter is a u8 slot index (0-3). The original copies the 4-byte table {0,3,6,9} to its stack
frame and indexes it with the raw register, so the check's random u8 values (0..255) make it read its own
saved registers / memory beyond the stack top, which C cannot reproduce. param1 is declared BOOL so the
check only feeds 0/1 (table values 0 and 3); everything else (sprite index, x/y math, s16 narrowing) is checked.
With `u8 param1` the check fails only on those out-of-range indexes.
Confirmed with `u8 param1` and a private sandbox copy that limits param1 to 0..3: 2000 trials agree.
