# ov40_0222F09C

PASS; about 14% of the trials are inconclusive. The original indexes a three-entry stack table with
the unchecked fourth argument and a 30-entry stack rank array with an unchecked loop index (a
signed halfword or a difference of two ints), and writes the rank array past its end with counts read
from that table, so for the sandbox's arbitrary inputs it often smashes its own saved lr and never
returns. Those trials cannot finish on the original side.

The C models the original's frame so that out-of-range reads see the same words: the table is 0x298
bytes below the entry stack pointer, the rank array 0x8C bytes below it, the species-name buffer
between them is zero, the five pushed registers sit just under the entry sp (r4-r6 are listed as asm
clobbers so clang pushes the same five registers as the original), and the original's own scalar
locals just below the table are rebuilt with the values they hold when the rank is read. Reads below
the original's sp and inside the 64K stack window are zero.

The stack arguments of calls (AddTextPrinterParameterizedWithColor's y/speed/color) are not compared
by the check; they were matched by reading the asm.
