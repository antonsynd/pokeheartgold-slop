# ov102_021EC3D4

The asm loads both blend planes with `ldmia r2!, {r1, r2}`, whose base register is also in the list. On the
ARM9, Thumb `ldmia` does not write the base back in that case. The lifter used to write it back, so the
original side never finished and every trial was inconclusive, for Ghidra's draft too. With the lifter
fixed, the C here, which follows the asm and the Platinum twin ov20_021D4F74, passes on 2,000 inputs.
